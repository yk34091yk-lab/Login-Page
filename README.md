# Login Page

This is a simple Login Page created using HTML, CSS, and JavaScript.

I made this project to improve my front-end web development skills and understand how a login interface is designed. The page has a clean layout and is responsive, so it works on both desktop and mobile devices.

## Features

- Responsive design
- Simple and clean UI
- HTML, CSS and JavaScript
- Easy to understand code

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Future Improvements

- Add form validation
- Connect with a backend
- Add a "Forgot Password" feature
